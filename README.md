# 🏡 Nyumba 360 – Smart Real Estate Platform

**Nyumba 360** is a modern real estate platform designed to simplify how people discover, compare, buy, sell, and rent properties. The platform aims to connect property buyers, tenants, landlords, agents, and property developers through an intuitive, technology-driven experience.

With intelligent property recommendations, interactive maps, property comparisons, and digital payment integration, Nyumba 360 seeks to make real estate transactions more accessible, transparent, and convenient.

## ✨ Key Features

### 🏘️ Property Listings
- Browse properties available for sale or rent.
- View property images, descriptions, prices, and locations.
- Explore residential, commercial, and land listings.
- Access detailed property information.

### 🔍 Smart Property Search
- Search properties by location, price, and property type.
- Apply filters to narrow down search results.
- Compare multiple properties side by side.
- Save favorite properties for future reference.

### 🤖 AI-Powered Real Estate
- Intelligent property recommendations based on user preferences.
- AI-assisted property discovery and matching.
- Property valuation estimates.
- Rental yield and return-on-investment (ROI) analysis.
- Construction cost estimation tools.

*AI-powered features are subject to implementation and data availability.*

### 🗺️ Interactive Maps
- Explore properties by geographical location.
- Discover properties in preferred neighborhoods.
- Support location-based property discovery.

### 🔄 Property Comparison
- Compare property prices, locations, sizes, and features.
- Make more informed property decisions.
- Evaluate potential investment opportunities.

### 🏠 Virtual Property Tours
- Support immersive property exploration.
- Present property images and available virtual-tour media.
- Help users assess properties remotely.

### 💳 Payments and Monetization
- Planned M-Pesa integration for supported transactions.
- Potential premium property listings and promotional placements.
- Support for future subscription-based services.

### 👤 User Accounts and Management
- User authentication and account management.
- Support for property owners, agents, and property seekers.
- Property listing management.
- Saved properties and personalized experiences.

## 🚀 Getting Started

### Prerequisites

Before running the project locally, ensure you have the required tools installed:

- Node.js
- npm, pnpm, or the package manager used by the project
- Git
- Access to any required database or external API services

### Installation

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd YOUR_PROJECT_FOLDER
```

**3. Install dependencies**

For npm:

```bash
npm install
```

For pnpm:

```bash
pnpm install
```

Use the package manager and commands supported by your repository.

**4. Configure environment variables**

Create a `.env` file in the project root if required by the application.

Example:

```env
DATABASE_URL=
AUTH_SECRET=
MAPS_API_KEY=
AI_API_KEY=
MPESA_CONSUMER_KEY=
MPESA_CONSUMER_SECRET=
```

These are illustrative placeholders, not verified variable names from the current application. Configure only the variables required by your actual codebase. Keep secret keys private and never commit production credentials to GitHub.

**5. Start the development server**

For npm projects:

```bash
npm run dev
```

For pnpm projects:

```bash
pnpm run dev
```

Open the local URL printed in your terminal.
